Getting started

Installation

1

Download the module

After purchase, download the ZIP from the Odoo App Store. Extract to get the vintage_theme folder.

2

Add to your addons path

Copy the folder into your custom addons directory and make sure the path is listed in odoo.conf under addons_path.

3

Update the apps list

Enable developer mode, then go to Apps → Update Apps List. Search for "Vintage Theme" and click Install.

4

Refresh and enjoy

Hard refresh your browser (Ctrl+Shift+R or Cmd+Shift+R) to clear the asset cache. Done.
